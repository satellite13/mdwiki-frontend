# Редизайн иконки mdwiki

## Цель

Заменить декоративную иконку с двумя листами, градиентами, бликом и тенями на строгий продуктовый знак, который уверенно читается как favicon и как марка в интерфейсе.

## Утверждённое направление

«Вырезанный блок»:

- квадрат 26×26 в `viewBox="0 0 32 32"`, позиция `(3, 3)`;
- скругление `rx="4"`;
- один фирменный цвет `#0d9488`;
- две белые открывающие квадратные скобки `[[`;
- скобки строятся SVG-path, а не текстовым глифом;
- никаких градиентов, теней, бликов, сгибов бумаги или дополнительных слоёв.

## Геометрия

Базовый path скобок:

```svg
<path
  d="M14 8h-3.5A1.5 1.5 0 0 0 9 9.5v13a1.5 1.5 0 0 0 1.5 1.5H14
     M23 8h-3.5A1.5 1.5 0 0 0 18 9.5v13a1.5 1.5 0 0 0 1.5 1.5H23"
  fill="none"
  stroke="#fff"
  stroke-width="2.6"
  stroke-linecap="square"
/>
```

Единый контракт: `stroke-width="2.6"` во всех размерах (16, 24, 32 px) и во всех артефактах (`MdwikiMark.vue`, `favicon.svg`). Визуальная проверка подтвердила читаемость при 16 px.

## Компоненты

- `public/favicon.svg`: автономный SVG с фиксированными бирюзовым и белым цветами.
- `src/components/layout/MdwikiMark.vue`: та же геометрия без `<defs>`, фильтров и `useId()`. Цвет блока фиксированный `#0d9488`, скобки белые.
- Места использования в `AppHeader.vue` и `ReadingToolbar.vue` не меняются.

## Поведение и доступность

- Компонент остаётся декоративным: `aria-hidden="true"` и `focusable="false"`.
- Иконка должна одинаково работать на светлом и тёмном фоне.
- SVG не должен зависеть от CSS `currentColor`, чтобы знак сохранял утверждённые цвета во всех местах.

## Проверка

1. Сравнить `favicon.svg` и `MdwikiMark.vue`: геометрия и цвета совпадают.
2. Проверить отображение в размерах 16, 24 и 32 px.
3. Проверить светлую и тёмную темы.
4. Запустить существующие проверки фронтенда и убедиться, что Vue/TypeScript не получили новых ошибок.

## Вне задачи

- Изменение текстового логотипа `mdwiki`.
- Смена `theme-color`.
- Анимация иконки.
- Разработка дополнительных вариантов логотипа.
