# Настройка комментария при завершении задач и «завершить все»

## Цель

Дать пользователю в профиле отключить модалку комментария при чеке задачи на `/tasks`, и при отключённом комментарии — массово завершать все открытые задачи документа одним чекбоксом в шапке группы.

## Поведение

| Настройка «Спрашивать комментарий» | Клик по задаче | Чекбокс «все» в шапке документа |
| --- | --- | --- |
| Вкл (по умолчанию) | Модалка с необязательным комментарием | Скрыт |
| Выкл | Сразу `POST /tasks/complete` без summary | Показан (редактор, документ не locked) |

«Завершить все»: confirm → последовательные complete без summary. После каждого успешного complete перечитывать `/tasks/open`, брать актуальный `updatedAt` (и снимок) для следующей задачи того же `documentId`. При 409 — как сейчас: предложить reload.

## Хранение

Только frontend: `localStorage` ключ `mdwiki-task-ask-comment` (`'1'` / `'0'`), обёртка `localPreferences`. API не меняем.

## UI

- Профиль: секция «Задачи» с одним чекбоксом.
- `/tasks`: в `group-header` слева от заголовка — общий чекбокс (только если ask-comment выкл).

## Вне scope

Серверные preferences, bulk-endpoint, комментарий при массовом завершении.
