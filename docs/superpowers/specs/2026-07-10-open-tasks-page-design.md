# Страница открытых задач

## Цель

Добавить в MDWiki страницу `/tasks`, которая показывает все незакрытые Markdown-задачи формата `- [ ] …`, сгруппированные по исходным документам. Пользователь может открыть документ-источник или завершить задачу непосредственно из списка.

## Границы

- Учитываются только открытые задачи формата `- [ ]`.
- Агрегация и изменение Markdown выполняются сервером, а не через загрузку всех документов во фронтенд.
- Завершение задачи опционально принимает summary.
- Задачи заблокированных документов видимы, но не могут быть завершены.

## API

`GET /api/tasks/open` возвращает снимки открытых задач: `documentId`, `slug`, `documentTitle`, `taskText`, `sourceOffset`, `sourceLine`, `updatedAt` и `locked`.

`POST /api/tasks/complete` принимает `documentId`, `updatedAt`, `sourceOffset`, `sourceLine` и необязательный `summary`. Сервер проверяет, что документ не заблокирован, `updatedAt` совпадает, а исходная строка в `sourceOffset` всё ещё содержит открытую задачу. Затем заменяет `[ ]` на `[x]`, а при непустом summary добавляет после задачи Markdown-цитату с префиксом `> ` для каждой строки.

`409 Conflict` означает, что документ изменился или снимок задачи больше не совпадает. Позиция не является постоянным идентификатором и действительна только для заданного `updatedAt`.

## UI

- Новый маршрут `/tasks` и ссылка в основной навигации.
- Группы задач по документу; заголовок открывает исходный документ.
- Чекбокс открывает форму с необязательным многострочным summary.
- После успешного завершения список перезагружается.
- У задач locked-документов чекбокс отключён, переход к документу доступен.

## Тестирование

- Сервер: сканирование, code blocks, completion с/без summary, locked, конфликт версии и смещения.
- Фронтенд: группировка, переход, locked, summary-dialog, payload без/с summary, success reload, `409` и сетевые ошибки.
